# LIMPI

**LuPi13's Integrated Minecraft Plug-In**

능력 뽑기와 경제 시스템을 하나로 묶은 Paper 서버용 플러그인입니다.
플레이어는 뽑기로 고유한 능력을 얻어 싸우고, 퀘스트로 상위 능력을 해금하며, 돈과 아이템을 사고팔며 서버 경제를 함께 만들어 갑니다.

## 주요 기능

### 능력
- 70개가 넘는 능력이 TROLL부터 MYTHIC까지 6개 등급으로 나뉘어 있습니다.
- 플레이어는 한 번에 하나의 능력을 가집니다. 능력마다 고유한 조작법과 효과, 연출이 있습니다.
- `/ability enemy`로 어떤 대상을 적으로 볼지(플레이어, 몹, 길들인 동물 등) 직접 정할 수 있고, 능력의 공격은 적으로 지정한 대상에게만 들어갑니다.

### 뽑기
- 뽑기권으로 무작위 능력을 얻고, 선택권으로 해금한 능력 중 원하는 것을 고릅니다.
- 천장이 있어 운이 나빠도 일정 횟수 안에 높은 등급을 얻습니다.
- 일정 시간마다 바뀌는 픽업 능력이 있어, 노리는 능력이 나올 확률이 올라갑니다.
- 뽑기권을 여러 번 눌러 여러 장을 동시에 뽑을 수 있습니다.

### 퀘스트
- 능력을 쓰다 보면 특정 조건에서 상위 능력이 해금됩니다.
- 조건이 감춰진 숨김 퀘스트도 있습니다. 능력을 충분히 쓰면 힌트가 열립니다.
- `/ability quest`에서 달성 여부와 진행도를 확인할 수 있습니다.

### 경제
- **계좌·송금:** 처음 접속하면 기본 소지금을 받고, 다른 플레이어에게 송금할 수 있습니다.
- **수표:** 돈을 수표 아이템으로 바꿔 주고받을 수 있습니다. 위조된 수표는 가려냅니다.
- **상점:** 서버 상점에서 아이템을 사고, 판매창에 아이템을 넣어 팔 수 있습니다.
- **장터:** 플레이어끼리 아이템을 등록하고 사고팝니다.
- **주식:** 일정 주기로 가격이 바뀌는 종목을 사고팔 수 있습니다.

### 안정성
- 모든 돈과 아이템 거래는 기록을 남기며 처리됩니다. 거래 도중 서버가 꺼져도 다음 접속 때 이어서 정리되어, 돈이나 아이템이 사라지거나 복제되지 않습니다.
- 데이터는 자동으로 백업됩니다.

## 대표 능력

| 능력 | 소개 |
| --- | --- |
| 회피 | 빠르게 두 번 웅크려 이동 방향으로 몸을 날립니다. 쓰다 보면 여러 상위 회피 능력으로 이어집니다. |
| 방패강타 | 방패를 든 채 전방으로 돌진해 부딪힌 적에게 피해를 줍니다. |
| 핸드캐논 | 왼손의 핸드캐논으로 작은 탄환을 연사합니다. |
| 시간 역행 | 3초 전의 위치와 체력으로 되돌아갑니다. |
| 웹슈터 | 거미줄을 쏘아 벽이나 몹에게 빠르게 끌려갑니다. |
| 은폐 | 게이지를 소모해 투명해지고 몹의 시선을 피합니다. |
| 밸런스 붕괴 | 단 한 번, 모든 것을 꿰뚫는 레일건을 쏩니다. |
| 함께 폭⭐사하자 | 죽으면 주변을 휩쓰는 대폭발을 일으킵니다. |

전체 능력과 상세 설명은 게임 안에서 `/ability dict`(능력 도감)로 볼 수 있습니다.

## 명령어

명령어 설명은 **[LIMPI 도움말](https://lupi13.github.io/LIMPI/)** 페이지에 있습니다.

- [명령어](https://lupi13.github.io/LIMPI/commands/): 능력·뽑기·퀘스트·계좌·수표·상점·장터·주식
- [관리자 명령어](https://lupi13.github.io/LIMPI/admin/): 능력 지정, 잔액 조정, 상점·주식 관리, 거래 복구, 권한 목록

게임 안에서 `/ability help`(`/ab help`), `/financial help`(`/fc help`)를 입력하면 나오는 도움말 책에서도 이 페이지로 갈 수 있습니다.

## 설치

1. [Releases](../../releases)에서 `LIMPI-x.x.x.jar`를 받습니다.
2. 서버의 `plugins` 폴더에 넣고 서버를 켭니다.

**요구 사항:** Paper 26.3, Java 25

## 설정

서버를 처음 켜면 `plugins/LIMPI` 폴더에 설정 파일이 만들어집니다. 파일을 고친 뒤 서버를 다시 켜면 적용됩니다.

| 파일 | 바꿀 수 있는 것 |
| --- | --- |
| `config.yml` | 능력·금융 시스템 켜기/끄기, 첫 소지금과 첫 뽑기권 수, 뽑기 등급 확률, 뽑기권 가격, 픽업 주기, 주식 변동 폭, 자동 백업 주기 등 |
| `ability/<능력>.yml` | 능력별 세부 수치(피해량, 쿨타임, 범위, 지속 시간 등) |
| `financial/sellPrice.yml` | 아이템 판매 가격 |
| `financial/shopRatio.yml` | 상점 판매 아이템과 가격 비율 |
| `financial/stock.yml` | 주식 종목 |

능력 수치는 `/ability reload`로 서버를 끄지 않고 다시 불러올 수 있고, 판매 가격·상점·주식은 관리자 명령으로도 바꿀 수 있습니다. 자세한 내용은 [관리자 명령어](https://lupi13.github.io/LIMPI/admin/)를 보세요.
