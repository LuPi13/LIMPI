# 효과의 공간·연산 경계

2026-10-10. 11개 능력의 방향 정규화는 normalizeSafely를 사용한다. Vector의 원본 변경 규약을 유지하고, 0/동일 위치/유효하지 않은 좌표는 유한한 0 벡터를 반환한다. 큰 수와 subnormal 작은 수는 최대 성분으로 먼저 나누어 정상 방향을 보존한다.

- WebShooter의 질량 비율과 ShieldStrike의 부피 나눗셈은 0 부피를 보호한다. 겹친 중심의 넉백이 NaN이 되지 않는다.
- Muspell의 동일 위치 검색은 0 방향 rayTrace를 하지 않는다. 추적 대상이 다른 월드로 이동하면 해제하고, 방향 보정이 정확히 상쇄되면 기존 방향을 유지한다.
- BladeLeaper는 정지한 순간 0 방향 rayTrace를 생략한다. 기존 gravity/수명과 다음 틱 이동은 유지한다.
- ImpactLanding은 기존 가우스 피해 곡선을 유지하되 검색 반경을 최대 128, 시각 효과 ring을 최대 16으로 제한한다. 각 각도별 smoke/flame 무작위 반복은 각각 최대 8회이다. sound/particle 속도도 표시 범위로 제한한다. 특히 외부 플러그인이 큰 낙하 피해를 전달해도 무제한 반복하지 않는다.
- 이러한 제한은 서버 작업량과 수치 안전성을 위한 정책이다. 대형 충격파의 범위/표시량은 이전보다 줄 수 있다. 다른 플러그인이 추가한 엔티티 수 자체를 제한하거나 실제 서버 성능을 보장하는 시험은 아니다.

전체 310개 시험과 test build가 통과했다. 새 9개 시험은 0/NaN/Infinity/큰 값/작은 값 방향, 일반 피해 곡선, 큰 낙하 피해의 공간/표시 경계, 확률 반복 종료·0 확률, 잘못된 입력 거부를 확인한다. 실제 Paper 이동/rayTrace/표시는 최종 서버 시험에서 확인한다.
