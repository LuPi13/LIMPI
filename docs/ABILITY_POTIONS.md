# 일시 포션의 소유권

2026-10-10. 통달·점프 충전·방패 돌진·엔티티 붙잡기·칼날 도약·죽음의 주사위 경고는 AbilityEffect의 potion lease를 사용한다. 능력 전환/quit/death/world/disable 및 개별 작업 종료 시 소유한 포션만 해제한다.

- 이미 외부의 동종 포션이 있으면 일시 능력 포션을 덮어쓰지 않는다. 약한 기존 포션도 보존하며 이전 효과를 추정하거나 새 지속 시간을 붙여 복원하지 않는다.
- 같은 scope의 포션만 새 레벨/기간으로 갱신할 수 있다. 다른 scope의 포션을 제거하거나 인수하지 않는다.
- 외부의 추가/변경/제거 이벤트가 발생하면 소유권을 포기한다. 동일한 레벨·표시의 외부 변경과 숨겨진 낮은 단계 효과도 보호한다. [Paper EntityPotionEffectEvent](https://jd.papermc.io/paper/26.3/org/bukkit/event/entity/EntityPotionEffectEvent.html).
- 자체 API 호출과 해당 이벤트 객체를 연결한다. 자체 호출 중 다른 리스너의 중첩 변경은 별도 이벤트이므로 소유권을 무효화한다. 단순히 Cause.PLUGIN만으로 소유권을 판단하지 않는다.
- 해제할 때도 실제 증폭/ambient/particles/icon이 소유한 값인지 확인한다. 외부 변경을 관측했다면 값이 같아도 제거하지 않는다. 포션 변경 취소를 강제로 우회하지 않는다.
- 외부 변경 후에는 일시 LIMPI 효과가 자연 만료까지 남을 수 있다. 안전하게 구별할 수 없는 숨겨진 외부 포션을 제거하지 않는 정책이다.
- 쿠키·설탕은 소비로 획득한 효과이므로 이 lease에 포함하지 않는다. 능력 변경만으로 이미 획득한 소비 보상을 회수하지 않는다. 설탕의 물품 소비/결과 기록 정비는 별도로 진행한다.

전체 289개 시험과 test build가 통과했다. 새 7개 시험은 무효화·같은 외형의 외부 교체·scope 경쟁·증폭 변경·entity/type 분리·반복 해제를 확인한다. 실제 Paper 중첩 이벤트, 숨겨진 포션, 취소·자연 만료 및 종료 처리는 서버 시험에서 확인한다. 실행 중 프로세스 강제 종료 후 포션의 영구 저장/정리는 아직 이 in-memory lease의 보장 범위에 포함하지 않는다.
