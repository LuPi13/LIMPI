# 능력 작업과 자원 수명

2026-10-10. AB-01/03/04/05/06 및 AB-08의 수명 관리 범위.

- 능력 객체 생성 시 반복 작업을 시작하지 않는다. 등록 후 start, 종료 시 stop을 호출한다. 에너지/좀비 반복 작업은 공통 runtime이 소유한다.
- 플레이어 상태의 키는 UUID다. 능력 전환·이탈·사망·월드 이동에서 상태와 effect scope를 정리한다. 작업은 접속·사망·월드·저장된 능력·물품 복구 차단 상태를 검사한다.
- scope는 역순으로 자원을 한 번만 해제한다. 초기화 일부 실패, 재진입, 개별 해제 및 보고 함수의 예외에도 남은 정리를 계속한다. 종료 후 새 scope 생성은 거부한다.
- 반복/지연 작업, 웹슈터 레이저, 검·통달 표시 엔티티, 불덩이 Marker, 붙잡기 상태는 scope에 연결한다. 일시 엔티티는 persistent=false다. 몹 변환으로 만든 실제 몹은 게임 결과이므로 일시 정리 대상에서 제외한다.
- 임시 속성은 limpi:ability/... transient modifier다. 기존 base value나 다른 플러그인 modifier를 덮어쓰지 않는다. 점프·운동·중력 제한과 좀비 방어력에 적용했다. 좀비 야간 처리에서 첫 플레이어 후 전체 반복을 종료하던 문제를 제거했다.
- 레일건은 공통 구현으로 충전/발사/종료를 관리한다. 지연 0과 소수 가속 시간을 허용하고 무한값·잘못된 크기·시간 합 오버플로는 생성 전에 거부한다. 오버밸런스 소모 후 진행 중인 발사 scope만 보존하며 새 능력 선택에서는 취소한다.
- 사망 후 폭발하는 LetsBoom은 명시적으로 죽은 상태에서도 시작/진행할 수 있다. 기존 효과는 사망 시 닫고 사망 이벤트에서 새 폭발 효과를 만든다. 이탈·월드 이동·능력 변경·종료 제한은 그대로 적용한다.

## 검 던지기 반환

생존 모드에서 원본 검 한 개 회수와 내구도 적용 후 반환 권리 예약을 공통 회수 원장으로 연결했다. 검이 부서지면 반환을 예약하지 않는다. 기존 metadata, 커스텀 최대 내구도 및 파괴불가 여부를 보존한다. Creative는 검을 회수하거나 반환하지 않는다.

물리 회수 checkpoint가 확인된 뒤 동일 DB transaction에서 미수령 검과 회수 DONE을 기록한다. 연출 정상 종료/취소 시 다음 틱 claim을 시도한다. 이탈·사망·disable·프로세스 중단에서 아직 돌려주지 않은 검은 미수령으로 남으며 다음 복구/claim 때 지급한다. 공간 부족은 월드에 떨어뜨리지 않고 미수령으로 유지한다. 연출 중 직접 claim하면 먼저 돌려받을 수 있으나 기존 material cooldown은 유지한다.

실제 회수가 불확실하면 원본/반환 둘 중 하나를 임의로 지급하지 않는다. 기존 financial removal의 오프라인 관리자 removed|retained 판단으로 복구한다. 원장이 검 한 개 차감과 정확한 source payload를 검증하며 요청 replay는 추가 차감/추가 반환을 만들지 않는다.
