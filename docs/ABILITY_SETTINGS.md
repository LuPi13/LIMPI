# 능력 설정과 등록 계약

2026-10-10. 설정을 사용하는 31개 능력의 기본값·타입·범위는 `config/AbilitySpecs.kt` 한곳에서 정의한다. 새 설정을 추가할 때 해당 정의와 사용하는 handler를 함께 변경한다. 능력 객체 생성은 서버·플러그인 조회나 작업 시작을 하지 않으며, bootstrap의 `AbilityManager.initialize(plugin)`에서 소유 플러그인을 연결하고 설정 검증 뒤 start를 호출한다.

## 저장과 실행

- 기존 파일을 strict YAML로 읽고 복사본에서 누락 필드만 보완한다. 0/false는 명시적 값이다. 알 수 없는 사용자 필드는 보존한다.
- schemaVersion은 누락/1만 허용한다. 알려진 모든 필드와 교차 조건이 통과한 뒤에만 누락 기본값/schema를 원자 저장한다. 잘못된 타입·값·YAML·미래 schema는 원본 파일을 덮어쓰지 않고 시작 실패에 파일 경로를 포함한다.
- 실행 handler는 불변 AbilitySettings를 읽는다. asConfiguration은 독립 복사본이며 런타임 값을 변경하지 못한다. 외부 파일 변경을 실행 중 자동 적용하지 않는다.
- 정수는 Int/Long 원본만 허용하고 Int 범위를 확인한다. 확률은 0..1, 공간 범위는 최대 128, 물리 속도 등은 최대 64, 반복 주기·나눗셈의 분모는 양수를 요구한다. 정확한 필드별 경계는 AbilitySpecs를 기준으로 한다.
- 레일건의 지연 0과 소수 가속 시간은 지원한다. 수명/지연 합계, 점프 게이지 곱셈, 통달 종료 시각은 Int overflow를 사전 거부한다. 연금술 가중치 합은 1이어야 한다.
- 에메랄드 수리량 0, 쿠키 지속 시간/레벨 0, 통달 지속 시간 0은 해당 효과를 비활성화한다. 통달 저항/신속 레벨 0은 해당 포션을 생성하지 않는다. 무료 부스터 비용 0은 정상 동작한다.
- Titan은 자체 설정을 사용하지 않으므로 빈 titan.yml 생성을 중단한다. 기존 파일을 삭제하지 않는다.

## 검증 범위

전체 269개 시험과 test build가 통과했다. 새 14개 시험은 전체 기본값, 부분 설정, 0/false 보존, 불변 값, 손상 원본 보존, 범위·타입·교차 조건, 실제 42개 레지스트리의 서버 없는 생성 및 퀘스트 메타데이터 연결을 확인한다. 실제 Paper enable/이벤트·포션·이동 동작은 최종 서버 시험에서 확인한다.
