## 원본과 다른 점

- **갑옷:** 원본 은폐·소멸의 걸음은 갑옷을 인벤토리에서 빼 두었다. 이식본은 물품을 옮기지 않고, 다른 플레이어에게 빈 갑옷을 보이게 하며(종료 시 복원) 은폐는 방어력·방어 강도를 0으로 만든다. 보호 인챈트는 그대로 적용된다. 갑옷이 보이므로 은폐 중 몹은 2.5블록(`mob_detect_range`) 밖에서 플레이어를 새로 노리지 않는다.
- **이동:** 회피 상위 능력은 LIMPI 회피의 이동(`velocity`, `allowJump`)을 그대로 쓴다. 쿨타임은 원본의 회피 대비 비율로 맞췄다(LIMPI 회피 5초): 회피+ 2.5초, 반사신경·치명적인 회피 5초, 엔드의 회피·겨울의 장막·소멸의 걸음 10초(엔드의 회피·겨울의 장막은 사용자 조정). 겨울의 장막은 `freeze_ticks`(기본 10초) 동안 적을 완전히 얼린다.
- **대상:** 겨울의 장막 빙결, 몹 표적 해제(은폐·소멸의 걸음)는 적 또는 자신을 노리는 몹에게만 적용한다(원본은 주변 전체).
- **은폐 게이지:** 사망·접속 종료·월드 이동 때 초기값으로 돌아간다(원본은 서버 세션 동안 유지). 초은폐의 회복 1.5배는 초당 고정 1.5다.
- **판정 보정:** 치명적인 회피의 처치 판정, 불타는 돌진의 처치 판정은 실제 피해 적용 후 대상의 사망으로 확인한다(원본은 피해 전 추정, 치명적인 회피는 1.5배를 두 번 계산하던 버그가 있었다).
- **직선 화살:** 화살을 새로 만들지 않고 같은 화살을 멈췄다가 빠르게 발사해 피해·관통·포션·주울 수 있는지 등 화살 정보를 보존한다. 적중 시 원래 발사 속도로 되돌려 피해가 일반 화살과 같다.
- **광석 세공사:** 구리 변환은 연금술 회수 기록(`ALCHEMY`)을 재사용하고, 에메랄드 수리는 기존 에메랄드 수리처럼 클릭 이벤트 안에서 바꾼다. 원석 제련은 원본처럼 도구 종류와 상관없고 원석 블록도 포함한다.
- **포효하는 불길:** 전방 공기 블록에 불을 놓을 때 건축 보호 플러그인 검사를 하지 않는다(블런더 부스터와 같음).
- **파티클:** Paper 26.x에서 데이터가 필요한 파티클(`SPELL_INSTANT` 등)은 다른 파티클로 바꿨다.

## 2차 이식 변경 사항 (2026-10-11 사용자 확정)

원본과 다른 판단이다. 대상 제한(적에게만), 진짜 핸드'캐논' 지형 파괴·0.5초 쿨타임·10초 수명, 카운터 1회 반격(상자 판정), 매의 눈 표식은 발광과 함께 만료, 시간 역행은 F키만으로 발동, TRIGGER FINGER!는 원본처럼 날아가는 자기 탄환 20발 이상으로 판정, 그 밖의 아래 변경을 사용자가 확정했고(스텔스 백스탭·고스트 스탭은 제외하기로 함), 매의 눈 추가 아이템은 생존에서 얻을 수 없는 아이템(기반암·엔드 포털 틀·스폰 알·좀벌레 블록 등)을 제외하기로 확정했다.

- **대상 제한:** 원본은 주변 모든 생명체를 때리거나 약화했지만 이식본은 `isEnemy` 적에게만 적용한다(핸드캐논 계열 탄환·익스플로전 무브·진짜 핸드'캐논' 폭발·카운터 반격·시공간 붕괴·매의 눈 표식).
- **진짜 핸드'캐논':** 원본 설명대로 지형을 부순다(`break_blocks: true`). 폭발 피해는 적에게만. 새로 0.5초 쿨타임, 10초 뒤 자동 소멸. 화약은 회수 기록을 거쳐 1개 소모.
- **오프핸드 마스터 퀘스트:** 원본에서도 달성 불가(보상 능력 없음)라 이식하지 않았다.
- **매의 눈:** 플레이어 처치 시 전리품 2배는 아이템 복제가 되므로 적용하지 않는다. 추가 무작위 아이템에서 관리자 전용 아이템과 생존에서 얻을 수 없는 아이템을 제외한다.
- **시간 역행+:** 1.5배는 회복에만 적용한다(원본은 체력 감소도 1.5배라 사망할 수 있었다). 회복은 최대 체력을 넘지 않는다.
- **카운터:** 0.5초 판정 동안 첫 피해에만 한 번 반격한다(원본은 피해마다 반격). 공허·/kill·월드 경계 피해는 반격·무시하지 않는다.
- **투척 설치:** 주 손 블록만, 일반 블록만(이름·인챈트·내용물 있는 블록, 문·침대 제외) 던진다. 0.25초 간격 제한, 블록 설치 이벤트로 건축 보호 플러그인을 존중, 설치 불가 시 아이템으로 떨어뜨린다.
- **광전사:** 배율을 최대 체력 비례로 계산한다(최대 체력 20에서는 원본과 같고, 20 초과 시 원본은 오히려 약해지거나 음수가 됐다).
- **집중의 활시위:** 활 시위를 놓거나 취소하면 공중 정지가 끝난다. 크리에이티브 비행 중에는 동작하지 않는다.
- **차지샷:** 충전 중 사망하면 자동 발사하지 않는다.

## 서버 확인

단위 시험은 등록·설정·퀘스트 진행도까지만 확인한다. 각 능력의 실제 동작, 퀘스트 달성, 갑옷 표시 복원(종료·사망·이탈·능력 변경·플러그인 종료)은 서버에서 확인해야 한다.
# AlchemyPlus 이식 (2026-10-11, 작업 브랜치)

`alchemy_plus` / 연금술+...? / EPIC(임시) / QUEST, `lotto` / 복권 당첨!(GOLD)을 등록했다. 원본 B* 대신 연금술(RARE) 이상의 EPIC을 선택했다. 구리 주괴 10개를 석탄·철 조각·철 주괴·금 조각·금 주괴·레드스톤·청금석·에메랄드·다이아몬드·네더라이트 주괴 중 1개로 바꾼다. 원본 확률은 각각 5%, 20%, 10%, 25%, 20%, 10%, 5%, 4%, 0.9%, 0.1%다. 새 spec에서 합계 1과 범위를 검증한다.

LIMPI의 기존 연금술과 같은 회수 checkpoint·frozen 결과·지급 저널을 사용한다. 원본의 world drop 대신 인벤토리 지급/공간 부족 미수령으로 보존한다. 원본의 소리와 네더라이트·다이아몬드 추가 소리를 사용한다. 연금술의 네더라이트 결과가 정산 완료되면 `Lotto`를 완료한다. 회수 정산과 같은 DB transaction에 `quest_trigger/<owner>/lotto` 증거를 남기고, 지급 복구 후에도 완료를 재시도하므로 crash 후 재추첨 없이 해금한다. 광석 세공사와 연금술+ 자체의 결과는 이 퀘스트 트리거에 포함하지 않는다.
