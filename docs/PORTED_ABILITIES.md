# GotchaAbility에서 이식한 능력

2026-10-11, 브랜치 `feature/port-gotcha-abilities`. 원본은 `../GotchaAbility/src/main/java/yasking/lupi13/gotchaability/abilities/passive`. 등급·이름·설명 문구는 임시값이며 사용자가 조정한다. 등급 대응은 원본 C→COMMON, B→RARE, A→EPIC, S→LEGENDARY, SS→MYTHIC을 기준으로, 상위 능력이 원래 능력보다 낮아지지 않게 맞췄다. 수치는 `plugins/LIMPI/ability/<codeName>.yml`(정의: `config/specs/*Specs.kt`)에서 바꾼다.

## 능력

| 능력 | codeName | 등급 | 획득 |
| --- | --- | --- | --- |
| 회피+ | `dodge_plus` | RARE | 퀘스트 회피의 달인 (회피 100회) |
| 엔드의 회피 | `end_dodge` | EPIC | 퀘스트 너의 회피는 (주변 엔더맨 10마리 이상에서 회피) |
| 번개와 같은 반사신경 | `light_reflex` | EPIC | 퀘스트 이거면 충분해 (회피 직후 폭발에서 생존) |
| 소멸의 걸음 | `invisible_dodge` | LEGENDARY | 퀘스트 굳이 회피해야해? (투명 상태에서 회피) |
| 치명적인 회피 | `critical_dodge` | LEGENDARY | 퀘스트 전형적인 회피 클리셰 (회피 직후 적 일격 처치) |
| 겨울의 장막 | `winter_shroud` | LEGENDARY | 퀘스트 바람처럼 차갑게 (빠른 속도로 회피) |
| 방패강타+ | `shield_strike_plus` | EPIC | 퀘스트 완벽한 거리조절 (방패강타 돌진 끝에 적과 충돌) |
| 포효하는 불길 | `roaring_flame` | EPIC | 퀘스트 불타는 돌진 (불타는 상태로 방패강타 처치) |
| 광석 세공사 | `metal_smith` | EPIC | 퀘스트 마스터 대장장이 (연금술·뜨거운 곡괭이·에메랄드 수리 모두 해금) |
| 직선 화살 | `linear_bow` | EPIC | 뽑기 |
| 은폐 | `cloak` | LEGENDARY | 뽑기 |
| 초은폐 | `super_cloak` | MYTHIC | 퀘스트 뫼비우스 반응로 (은폐 게이지 200을 끊지 않고 모두 사용) |

회피 계열 퀘스트는 회피(`dodge`) 능력, 방패 퀘스트는 방패강타(`shield_strike`), 뫼비우스 반응로는 은폐(`cloak`) 사용 중에만 달성한다. 회피 횟수는 프로필 `quest.dodge_count`에 원자적으로 누적한다(`QuestManager.progress`). 마스터 대장장이는 접속·뽑기 해금·능력 선택 직후 해금 목록을 확인한다. 원본의 소멸의 걸음 상위 퀘스트(어둠 속으로→BlightRanger)는 범위 밖이라 옮기지 않았다.

## 원본과 다른 점

- **갑옷:** 원본 은폐·소멸의 걸음은 갑옷을 인벤토리에서 빼 두었다. 이식본은 물품을 옮기지 않고, 다른 플레이어에게 빈 갑옷을 보이게 하며(종료 시 복원) 은폐는 방어력·방어 강도를 0으로 만든다. 보호 인챈트는 그대로 적용된다. 갑옷이 보이므로 은폐 중 몹은 2.5블록(`mob_detect_range`) 밖에서 플레이어를 새로 노리지 않는다.
- **이동:** 회피 상위 능력은 LIMPI 회피의 이동(`velocity`, `allowJump`)을 그대로 쓴다. 쿨타임은 원본의 회피 대비 비율로 맞췄다(LIMPI 회피 5초): 회피+ 2.5초, 반사신경·치명적인 회피 5초, 엔드의 회피·겨울의 장막·소멸의 걸음 10초(엔드의 회피·겨울의 장막은 사용자 조정). 겨울의 장막은 `freeze_ticks`(기본 10초) 동안 적을 완전히 얼린다.
- **대상:** 겨울의 장막 빙결, 몹 표적 해제(은폐·소멸의 걸음)는 적 또는 자신을 노리는 몹에게만 적용한다(원본은 주변 전체).
- **은폐 게이지:** 사망·접속 종료·월드 이동 때 초기값으로 돌아간다(원본은 서버 세션 동안 유지). 초은폐의 회복 1.5배는 초당 고정 1.5다.
- **판정 보정:** 치명적인 회피의 처치 판정, 불타는 돌진의 처치 판정은 실제 피해 적용 후 대상의 사망으로 확인한다(원본은 피해 전 추정, 치명적인 회피는 1.5배를 두 번 계산하던 버그가 있었다).
- **직선 화살:** 화살을 새로 만들지 않고 같은 화살을 멈췄다가 빠르게 발사해 피해·관통·포션·주울 수 있는지 등 화살 정보를 보존한다. 적중 시 원래 발사 속도로 되돌려 피해가 일반 화살과 같다.
- **광석 세공사:** 구리 변환은 연금술 회수 기록(`ALCHEMY`)을 재사용하고, 에메랄드 수리는 기존 에메랄드 수리처럼 클릭 이벤트 안에서 바꾼다. 원석 제련은 원본처럼 도구 종류와 상관없고 원석 블록도 포함한다.
- **포효하는 불길:** 전방 공기 블록에 불을 놓을 때 건축 보호 플러그인 검사를 하지 않는다(블런더 부스터와 같음).
- **파티클:** Paper 26.x에서 데이터가 필요한 파티클(`SPELL_INSTANT` 등)은 다른 파티클로 바꿨다.

## 서버 확인

단위 시험은 등록·설정·퀘스트 진행도까지만 확인한다. 각 능력의 실제 동작, 퀘스트 달성, 갑옷 표시 복원(종료·사망·이탈·능력 변경·플러그인 종료)은 서버에서 확인해야 한다.
