# 능력 `/ability`

줄여서 `/ab`로도 입력할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/ability help` | 채팅에 명령어 사용법을 봅니다. |
| `/ability rates` | 이 서버의 등급별 뽑기 확률과 천장·픽업 규칙을 봅니다. |
| `/ability me` | 현재 내 능력의 상세 정보와 사용법을 봅니다. |
| `/ability shop` | 돈으로 뽑기권과 선택권을 사는 창을 엽니다. 기본 가격은 뽑기권 2,000원, 선택권 1,000~5,000원입니다. |
| `/ability select` | 해금한 능력 중 하나를 골라 적용합니다. 능력 등급에 맞는 선택권이 필요합니다. |
| `/ability dictionary` (`dict`) | 모든 능력을 볼 수 있는 도감을 엽니다. 우클릭하면 상세 정보를 봅니다. |
| `/ability enemy` | 능력이 피해를 줄 **적**의 범위를 정하는 창을 엽니다. |
| `/ability ceiling` (`pity`) | 내 천장 현황과 다음 뽑기의 실제 확률을 봅니다. |
| `/ability pickup` | 현재 픽업 능력과 다음에 바뀔 픽업 능력을 봅니다. |
| `/ability quest` | 퀘스트 달성 여부, 보상, 누적 진행도를 봅니다. |
| `/ability result <거래 ID>` | 확정된 내 뽑기·선택 결과를 다시 봅니다. 관리자가 안내한 경우에만 쓰면 됩니다. |

## 능력 얻기

- **뽑기권**을 손에 들고 우클릭하면 무작위 능력이 나옵니다. 여러 번 눌러 여러 장을 한꺼번에 뽑을 수 있습니다.
- 뽑기로 나온 능력은 **해금**됩니다. 해금한 능력은 `/ability select`에서 그 등급의 **선택권**을 써서 언제든 적용할 수 있습니다.
- 처음 접속하면 뽑기권과 선택권 몇 장을 받습니다.

## 뽑기 확률과 천장

등급은 TROLL, COMMON, RARE, EPIC, LEGENDARY, MYTHIC이 있습니다. 기본 설정에서는 다음과 같습니다.

- **LEGENDARY**는 기본 0.5%입니다. 마지막 LEGENDARY 뒤로 81번째 뽑기부터 확률이 5%p씩 올라가 늦어도 100번째에는 나옵니다.
- **EPIC**은 기본 3%입니다. 마지막 EPIC 뒤로 7번째 뽑기부터 확률이 30%p씩 올라갑니다.
- 두 등급 모두 나올 때 50% 확률로 **픽업 능력**이 나옵니다. 픽업이 아닌 능력이 한 번 나왔다면 다음 같은 등급은 픽업 능력으로 확정됩니다.
- LEGENDARY·EPIC이 아니면 1%로 **TROLL**이 나오며, TROLL 능력은 바로 강제 적용됩니다.
- 그 밖에는 30%로 RARE, 나머지는 COMMON입니다.
- 픽업 능력은 30분마다 바뀝니다.

정확한 값은 서버 설정을 따르므로 `/ability rates`와 `/ability pity`로 확인하세요.

## 퀘스트

- 능력을 쓰다가 특정 조건을 채우면 상위 능력이 해금됩니다.
- 조건이 `???`로 감춰진 **숨김 퀘스트**도 있습니다. 관련 능력을 충분히 쓰면 조건 자리에 힌트가 나타납니다.

## 적 범위

`/ability enemy`에서 플레이어, 몹, 길들인 동물 등 어떤 대상을 적으로 볼지 고릅니다. 능력의 공격은 적으로 지정한 대상에게만 들어갑니다.

관리자 명령어는 [관리자 명령어](admin.md#ability) 페이지를 보세요. 다른 명령어는 [명령어 목록](commands.md)에 있습니다.
