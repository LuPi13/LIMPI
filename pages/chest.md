# 상자 `/chest`

줄여서 `/ch`로도 입력할 수 있습니다. 금융 계좌의 돈으로 사는 개인 추가 인벤토리입니다.

| 명령어 | 설명 |
| --- | --- |
| `/chest` (`open`) | 내 상자를 엽니다. 아직 해금하지 않았다면 상자 상점을 엽니다. |
| `/chest help` | 채팅에 명령어 사용법을 봅니다. |
| `/chest shop` | 상자 상점을 엽니다. |
| <code>/chest auto [on&#124;off]</code> | 자동 저장을 켜거나 끕니다. `on`/`off`를 생략하면 켜짐과 꺼짐을 바꿉니다. |

## 상자 상점 { #shop }

| 상품 | 기본 가격 | 효과 |
| --- | --- | --- |
| 상자 해금 | 10,000원 | 9칸(1줄)짜리 상자를 엽니다. |
| 업그레이드 | 2줄 20,000원 · 3줄 40,000원 · 4줄 80,000원 · 5줄 160,000원 · 6줄 320,000원 | 한 번에 1줄(9칸)씩, 최대 6줄(54칸)까지 늘립니다. |
| 자동 저장 | 50,000원 | 인벤토리가 가득 찬 상태에서 주운 아이템을 상자에 넣습니다. |
| 엔더화 | 1,000,000원 | 죽어도 상자 안의 아이템을 떨어뜨리지 않습니다. |

- 상점에서 원하는 상품을 **좌클릭**하면 계좌에서 돈이 빠지고 바로 적용됩니다.
- 구매한 상품은 **환불되지 않습니다.**

## 상자 쓰기

- 일반 상자처럼 아이템을 넣고 뺄 수 있습니다. 클릭, Shift 클릭, 숫자키, 드래그 모두 됩니다.
- 일반 상자처럼 Q 키나 창 밖 클릭으로 아이템을 버릴 수 있고, 상자 창을 연 채로 바닥의 아이템을 주울 수도 있습니다.
- 커서에 아이템을 든 채로 창을 닫으면 그 아이템은 상자(자리가 없으면 인벤토리)로 들어갑니다.

## 자동 저장

- 인벤토리에 **하나도 들어가지 않을 때** 주운 아이템이 상자로 들어갑니다. 일부만 들어가면 들어가는 만큼은 인벤토리로 오고, 나머지는 다음에 주울 때 상자로 갑니다.
- 상자에 들어가면 화면 아래(액션바)에 "<아이템 이름>이(가) 자동 저장되었습니다"가 뜹니다.
- 상자도 가득 차면 아이템은 바닥에 그대로 남습니다.
- 다른 플레이어에게 지정된 아이템은 넣지 않습니다.
- 상자 창을 열어 둔 상태에서도 자동 저장됩니다.
- 자동 저장을 산 직후에는 켜져 있습니다. `/chest auto`로 켜고 끌 수 있습니다.

## 죽었을 때

- 엔더화하지 않은 상자는 죽으면 안의 아이템을 **모두 떨어뜨립니다.** 인벤토리 아이템과 함께 죽은 자리에 떨어집니다.
- 엔더화한 상자는 아무것도 떨어뜨리지 않습니다.
- 서버의 `keepInventory` 게임룰이 켜져 있으면 엔더화하지 않아도 떨어뜨리지 않습니다.

관리자 명령어는 [관리자 명령어](admin.md#chest) 페이지를 보세요. 다른 명령어는 [명령어 목록](commands.md)에 있습니다.
