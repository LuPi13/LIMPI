# 명령어

모든 플레이어가 기본으로 쓸 수 있는 명령어입니다. 서버 관리자가 권한을 바꿨다면 일부 명령어가 보이지 않을 수 있습니다.

## 능력 `/ability`

줄여서 `/ab`로도 입력할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/ability help` | 게임 안 도움말 책과 뽑기 확률을 봅니다. |
| `/ability me` | 현재 내 능력의 상세 정보와 사용법을 봅니다. |
| `/ability shop` | 에메랄드로 뽑기권과 선택권을 사는 창을 엽니다. |
| `/ability select` | 해금한 능력 중 하나를 골라 적용합니다. 능력 등급에 맞는 선택권이 필요합니다. |
| `/ability dictionary` (`dict`) | 모든 능력을 볼 수 있는 도감을 엽니다. 우클릭하면 상세 정보를 봅니다. |
| `/ability enemy` | 능력이 피해를 줄 **적**의 범위를 정하는 창을 엽니다. |
| `/ability ceiling` (`pity`) | 내 천장 현황과 다음 뽑기의 실제 확률을 봅니다. |
| `/ability pickup` | 현재 픽업 능력과 다음에 바뀔 픽업 능력을 봅니다. |
| `/ability quest` | 퀘스트 달성 여부, 보상, 누적 진행도를 봅니다. |

### 능력 얻기

- **뽑기권**을 손에 들고 우클릭하면 무작위 능력이 나옵니다. 여러 번 눌러 여러 장을 한꺼번에 뽑을 수 있습니다.
- 뽑기로 나온 능력은 **해금**됩니다. 해금한 능력은 `/ability select`에서 그 등급의 **선택권**을 써서 언제든 적용할 수 있습니다.
- 처음 접속하면 뽑기권과 선택권 몇 장을 받습니다.

### 뽑기 확률과 천장

등급은 TROLL, COMMON, RARE, EPIC, LEGENDARY, MYTHIC이 있습니다. 기본 설정에서는 다음과 같습니다.

- **LEGENDARY**는 기본 0.5%입니다. 마지막 LEGENDARY 뒤로 81번째 뽑기부터 확률이 5%p씩 올라가 늦어도 100번째에는 나옵니다.
- **EPIC**은 기본 3%입니다. 마지막 EPIC 뒤로 7번째 뽑기부터 확률이 30%p씩 올라갑니다.
- 두 등급 모두 나올 때 50% 확률로 **픽업 능력**이 나옵니다. 픽업이 아닌 능력이 한 번 나왔다면 다음 같은 등급은 픽업 능력으로 확정됩니다.
- LEGENDARY·EPIC이 아니면 1%로 **TROLL**이 나오며, TROLL 능력은 바로 강제 적용됩니다.
- 그 밖에는 30%로 RARE, 나머지는 COMMON입니다.
- 픽업 능력은 30분마다 바뀝니다.

정확한 값은 서버 설정을 따르므로 `/ability help`와 `/ability pity`로 확인하세요.

### 퀘스트

- 능력을 쓰다가 특정 조건을 채우면 상위 능력이 해금됩니다.
- 조건이 `???`로 감춰진 **숨김 퀘스트**도 있습니다. 관련 능력을 충분히 쓰면 조건 자리에 힌트가 나타납니다.

### 적 범위

`/ability enemy`에서 플레이어, 몹, 길들인 동물 등 어떤 대상을 적으로 볼지 고릅니다. 능력의 공격은 적으로 지정한 대상에게만 들어갑니다.

## 금융 `/financial`

줄여서 `/fi`, `/fc`로도 입력할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/financial help` | 게임 안 도움말 책을 봅니다. |
| `/financial me` | 내 계좌 잔액을 봅니다. |
| `/financial send <플레이어> <금액>` | 다른 플레이어에게 송금합니다. 수수료 5%(소수점 아래 버림)가 붙습니다. |
| `/financial check <금액>` | 그 금액의 수표를 발행합니다. |
| `/financial check redeem` | 손에 든 수표를 입금합니다. 수표를 들고 우클릭해도 됩니다. |
| `/financial sell` | 판매창을 엽니다. 팔 아이템을 넣고 오른쪽 아래 금을 누르면 팔립니다. |
| `/financial shop` | 서버 상점을 엽니다. |
| `/financial stock` | 주식 거래창을 엽니다. |
| `/financial stock show` | 상장된 종목 정보를 봅니다. |
| `/financial stock holdings` | 내 보유 수량, 원가, 손익을 봅니다. 상장 중지된 종목도 나옵니다. |
| `/financial market` | 플레이어 장터를 엽니다. |
| `/financial market add <코드> <가격>` | 손에 든 아이템을 장터에 올립니다. |
| `/financial market remove <코드>` | 내가 올린 매물을 내립니다. 아이템은 미수령함으로 돌아옵니다. |
| `/financial claim` | 인벤토리가 가득 차 받지 못한 아이템(미수령함)을 받습니다. |

### 수표

- 수표는 서버가 발행 기록을 가진 것만 입금됩니다. 아이템 이름이나 표시 금액을 바꾼 수표는 입금되지 않습니다.
- 수표를 받을 공간이 없으면 미수령함에 보관되며, `/financial claim`으로 받을 수 있습니다.

### 장터

- 코드는 **대문자 알파벳과 숫자 4글자**입니다. 예: `A1B2`
- 이미 쓰고 있는 코드는 쓸 수 없습니다.

### 미수령함

거래로 받을 아이템이 인벤토리에 들어가지 않으면 사라지지 않고 미수령함에 쌓입니다. 공간을 비운 뒤 `/financial claim`으로 받으세요.

### 주식

종목 가격은 일정 주기(기본 10분)마다 바뀌며, 기준 가격 쪽으로 조금씩 돌아오려는 성질이 있습니다.

## 상자 `/chest`

줄여서 `/ch`로도 입력할 수 있습니다. 금융 계좌의 돈으로 사는 개인 추가 인벤토리입니다.

| 명령어 | 설명 |
| --- | --- |
| `/chest` | 내 상자를 엽니다. 아직 해금하지 않았다면 상자 상점을 엽니다. |
| `/chest help` | 게임 안 도움말 책을 봅니다. |
| `/chest shop` | 상자 상점을 엽니다. |
| <code>/chest auto [on&#124;off]</code> | 자동 저장을 켜거나 끕니다. `on`/`off`를 생략하면 켜짐과 꺼짐을 바꿉니다. |

### 상자 상점

| 상품 | 기본 가격 | 효과 |
| --- | --- | --- |
| 상자 해금 | 10,000원 | 9칸(1줄)짜리 상자를 엽니다. |
| 업그레이드 | 2줄 20,000원 · 3줄 40,000원 · 4줄 80,000원 · 5줄 160,000원 · 6줄 320,000원 | 한 번에 1줄(9칸)씩, 최대 6줄(54칸)까지 늘립니다. |
| 자동 저장 | 50,000원 | 인벤토리가 가득 찬 상태에서 주운 아이템을 상자에 넣습니다. |
| 엔더화 | 1,000,000원 | 죽어도 상자 안의 아이템을 떨어뜨리지 않습니다. |

- 상점에서 원하는 상품을 **좌클릭**하면 계좌에서 돈이 빠지고 바로 적용됩니다.
- 구매한 상품은 **환불되지 않습니다.**

### 상자 쓰기

- 일반 상자처럼 아이템을 넣고 뺄 수 있습니다. 클릭, Shift 클릭, 숫자키, 드래그 모두 됩니다.
- 일반 상자처럼 Q 키나 창 밖 클릭으로 아이템을 버릴 수 있고, 상자 창을 연 채로 바닥의 아이템을 주울 수도 있습니다.
- 커서에 아이템을 든 채로 창을 닫으면 그 아이템은 상자(자리가 없으면 인벤토리)로 들어갑니다.

### 자동 저장

- 인벤토리에 **하나도 들어가지 않을 때** 주운 아이템이 상자로 들어갑니다. 일부만 들어가면 들어가는 만큼은 인벤토리로 오고, 나머지는 다음에 주울 때 상자로 갑니다.
- 상자에 들어가면 화면 아래(액션바)에 "<아이템 이름>이(가) 자동 저장되었습니다"가 뜹니다.
- 상자도 가득 차면 아이템은 바닥에 그대로 남습니다.
- 다른 플레이어에게 지정된 아이템은 넣지 않습니다.
- 상자 창을 열어 둔 상태에서도 자동 저장됩니다.
- 자동 저장을 산 직후에는 켜져 있습니다. `/chest auto`로 켜고 끌 수 있습니다.

### 죽었을 때

- 엔더화하지 않은 상자는 죽으면 안의 아이템을 **모두 떨어뜨립니다.** 인벤토리 아이템과 함께 죽은 자리에 떨어집니다.
- 엔더화한 상자는 아무것도 떨어뜨리지 않습니다.
- 서버의 `keepInventory` 게임룰이 켜져 있으면 엔더화하지 않아도 떨어뜨리지 않습니다.

## 공지 `/notice`

줄여서 `/no`, `/nt`로도 입력할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/notice help` | 게임 안 도움말 책을 봅니다. |
| `/notice show <날짜> [번호]` | 지난 공지를 다시 봅니다. 예: `/notice show 2026-10-14 001`. 번호를 생략하면 그날의 공지를 모두 봅니다. |
| `/notice list` | 보관 중인 공지의 날짜와 번호를 봅니다. 날짜나 번호를 누르면 그 공지가 나옵니다. 읽지 않은 공지는 노란색입니다. |
| `/notice unread` | 읽지 않은 공지를 모두 봅니다. |

- 공지가 올라오면 접속 중인 플레이어의 채팅창에 알림음과 함께 나옵니다.
- 접속해 있지 않을 때 올라온 공지는 다음에 접속하면 "읽지 않은 공지가 X건 있습니다!"로 알려 줍니다. 그 문구를 누르면 읽지 않은 공지가 모두 나옵니다.
- 공지는 기본 30일 동안 보관된 뒤 지워집니다.
