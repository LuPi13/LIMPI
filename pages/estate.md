# 사유지 `/estate`

줄여서 `/es`로도 입력할 수 있습니다. 금융 계좌의 돈으로 직육면체 구역을 사서 다른 사람이 건드리지 못하게 보호합니다.

| 명령어 | 설명 |
| --- | --- |
| `/estate help` | 채팅에 명령어 사용법을 봅니다. |
| `/estate select` | 구역 선택 모드를 켜거나 끕니다. |
| `/estate sky` | 선택한 구역의 위쪽을 하늘 끝까지 넓히거나 되돌립니다. |
| `/estate accept <사유지이름>` | 견적을 확인한 구역을 이 이름으로 삽니다. |
| `/estate deny` | 진행 중인 구매를 취소합니다. |
| `/estate overlaps` | 선택한 구역이 다른 사유지와 겹친 부분을 보여줍니다. |
| `/estate show [사유지이름]` | 사유지 테두리를 보여줍니다. 이름을 생략하면 구매 중인 구역입니다. |
| `/estate list` | 내 사유지와 공유받은 사유지 목록을 봅니다. |
| `/estate where` | 지금 서 있는 곳이 누구의 사유지인지 봅니다. |
| `/estate sell <사유지이름>` | 사유지를 매각합니다. |
| `/estate trust <사유지이름> <플레이어>` | 그 플레이어가 내 사유지에서 건축할 수 있게 합니다. |
| `/estate untrust <사유지이름> <플레이어>` | 공유한 건축 권한을 거둡니다. |

## 사는 법 { #buy }

1. `/estate select`로 선택 모드를 켭니다.
2. **빈손으로** 블록을 **좌클릭**하면 첫번째 좌표, **우클릭**하면 두번째 좌표가 정해집니다. 두 블록을 꼭짓점으로 하는 직육면체가 구역이 됩니다(두 블록 포함).
3. 두 좌표가 정해지면 구역 테두리에 파란 불꽃이 나타나고, 채팅에 크기와 가격이 나옵니다.
    - **[하늘까지 포함]**을 누르면 아래쪽은 그대로 두고 위쪽을 월드 꼭대기까지 넓힙니다. 위로 쌓을 공간까지 미리 확보할 때 씁니다.
    - 좌표를 다시 찍으면 견적이 새로 나옵니다.
4. **[승인]**을 누르고 이름을 붙여 `/estate accept 우리집`처럼 입력하면 계좌에서 돈이 빠지고 사유지가 됩니다.

| 항목 | 기본값 |
| --- | --- |
| 가격 | 블록 1칸당 **4원** (예: 16×16×20 = 5,120칸 = 20,480원) |
| 한 구역의 가로·세로 | 각각 최대 **128칸** |
| 높이 | 제한 없음 |
| 1인당 개수 | 최대 **10개** |
| 이름 | 공백 없이 1~16자, 내 사유지끼리 같은 이름 불가(대소문자 무시) |

- 다른 사람의 사유지와 **조금이라도 겹치면 살 수 없습니다.** **[여기를 누르면 겹치는 부분에 효과가 나타납니다]**로 겹친 곳을 확인하세요.
- **내 사유지끼리도 겹칠 수 없습니다.** 넓히고 싶으면 바로 옆에 붙여서 하나 더 사세요(붙어 있는 것은 괜찮습니다).
- 땅 밑을 얼마나 포함할지는 직접 정합니다. 아래 좌표를 깊게 찍을수록 지하까지 보호되고 그만큼 비쌉니다.

## 보호되는 것 { #protection }

주인과 공유받은 플레이어(`trust`)만 할 수 있고, 다른 사람은 막힙니다.

- 블록 부수기·설치, 양동이로 물·용암 붓기/뜨기
- 상자·화로 등 아이템이 든 블록 열기, 문·다락문·버튼·레버·침대 등 블록 사용
- 압력판·실 밟기, 경작지 밟기
- 동물·주민·액자·갑옷 거치대·그림·탈것 건드리기와 공격(몬스터와 플레이어는 보호하지 않습니다. **PvP는 막지 않습니다.**)
- 표지판 고치기, 뼛가루·부싯돌·괭이·도끼·삽 등을 블록에 쓰기

밖에서 들어오는 것도 막습니다.

- 폭발: TNT 대포, 크리퍼, 위더, 화염구, 엔드 크리스탈, 침대·리스폰 정박기 폭발. 폭발은 일어나지만 사유지 안 블록은 부서지지 않습니다. 주인이 사유지 **안에서** 붙인 TNT는 사유지 블록도 부숩니다.
- 피스톤: 밖에 있는 피스톤(비행체 포함)은 사유지 블록을 밀거나 당기지 못하고, 사유지 안으로 블록을 밀어 넣지 못합니다.
- 밖에서 흘러드는 물·용암, 밖에서 번지는 불, 밖의 디스펜서가 쏘는 것, 밖에서 쏜 화살로 버튼 누르기
- 사유지 바닥 아래를 파서 모래·자갈 떨어뜨리기, 밖에서 모래·모루 떨어뜨려 쌓기
- 엔더맨·위더·파괴수·좀벌레가 블록 바꾸기, 좀비가 문 부수기
- 밖의 호퍼(호퍼 수레 포함)가 사유지 안 상자에서 아이템 빼 가기. 사유지 안의 호퍼끼리는 그대로 됩니다.
- 밖에서 자란 나무가 사유지 안으로 뻗기

먹기, 활 쏘기, 능력 아이템 쓰기처럼 블록을 바꾸지 않는 행동은 남의 사유지 안에서도 그대로 됩니다.

다른 사람의 사유지에 들어가면 액션바에 **"이 지역은 ○○님의 사유지 △△입니다."**가 잠깐 뜹니다.

## 매각 { #sell }

`/estate sell 우리집`을 입력하면 돌려받을 금액이 나오고, **[매각 확인]**을 누르면 매각됩니다.

- 기본으로 **구매할 때 낸 금액의 50%**를 돌려받습니다.
- 매각해도 그 자리의 블록은 그대로 남습니다. 보호만 사라지고, 다른 사람이 그 자리를 살 수 있게 됩니다.

## 공유 { #trust }

`/estate trust 우리집 친구이름`으로 친구가 그 사유지에서 주인처럼 건축·상자 사용을 할 수 있습니다. `/estate untrust`로 거둡니다. 공유받은 사유지는 `/estate list` 아래쪽에 나옵니다. 매각과 공유 설정은 주인만 할 수 있습니다.
