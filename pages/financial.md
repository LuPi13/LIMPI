# 금융 `/financial`

줄여서 `/fi`, `/fc`로도 입력할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/financial help` | 채팅에 명령어 사용법을 봅니다. |
| `/financial me` | 내 계좌 잔액을 봅니다. |
| `/financial send <플레이어> <금액>` | 다른 플레이어에게 송금합니다. 보내는 사람이 금액의 5%(소수점 아래 버림)를 수수료로 더 냅니다. |
| `/financial check <금액>` | 그 금액의 수표를 발행합니다. |
| `/financial check redeem` | 손에 든 수표를 입금합니다. 수표를 들고 우클릭해도 됩니다. |
| `/financial sell` | 판매창을 엽니다. 팔 아이템을 넣고 오른쪽 아래 금을 누르면 팔립니다. |
| `/financial sell price [아이템]` | 지금 1개를 팔면 받는 가격을 봅니다. 아이템을 생략하면 손에 든 아이템입니다. |
| `/financial shop` | 서버 상점을 엽니다. |
| `/financial stock` | 주식 거래창을 엽니다. |
| `/financial stock show` | 상장된 종목 정보를 봅니다. |
| `/financial stock holdings` | 내 보유 수량, 원가, 손익을 봅니다. 상장 중지된 종목도 나옵니다. |
| `/financial market` | 플레이어 장터를 엽니다. |
| `/financial market add <코드> <가격>` | 손에 든 아이템을 장터에 올립니다. |
| `/financial market remove <코드>` | 내가 올린 매물을 내립니다. 아이템은 미수령함으로 돌아옵니다. |
| `/financial claim` | 인벤토리가 가득 차 받지 못한 아이템(미수령함)을 받습니다. |

처음 접속하면 기본 설정에서 1,000원이 계좌에 들어 있습니다.

## 판매

- 가격이 정해지지 않은 아이템은 **0원**입니다. 판매창에 넣고 팔면 돈 없이 사라지므로, 버릴 아이템을 정리하는 데 쓸 수 있습니다. 판매 버튼(금)에 받을 금액이 미리 표시됩니다.
- 농장에서도 얻을 수 있는 아이템(토템, 엔더 진주, 철 주괴, 작물 등)은 **많이 팔수록 1개당 가격이 내려갑니다.** 처음 몇 개는 제값을 받고, 계속 팔면 최저 가격까지 내려갑니다.
- 내려간 가격은 시간이 지나면 돌아옵니다. 지금까지 판 개수가 기본 12시간마다 절반으로 줄어듭니다.
- 지금 가격은 `/financial sell price`로 확인할 수 있습니다.
- 셜커 상자 안의 아이템이나 인첸트는 가격에 들어가지 않습니다. 넣기 전에 확인하세요.

## 수표

- 수표는 서버가 발행 기록을 가진 것만 입금됩니다. 아이템 이름이나 표시 금액을 바꾼 수표는 입금되지 않습니다.
- 수표를 받을 공간이 없으면 미수령함에 보관되며, `/financial claim`으로 받을 수 있습니다.

## 장터

- 코드는 **대문자 알파벳과 숫자 4글자**입니다. 예: `A1B2`
- 이미 쓰고 있는 코드는 쓸 수 없습니다.
- 장터 창에서 매물을 **좌클릭**하면 삽니다. 인벤토리에 자리가 있어야 합니다. **우클릭**하면 판매자에게 값을 깎아 달라고 조릅니다.
- 내 매물이 팔리면 판매 수수료 5%를 뺀 금액이 계좌로 들어옵니다.
- 내가 올린 매물은 살 수 없습니다. 내리려면 `/financial market remove <코드>`를 씁니다.

## 미수령함

거래로 받을 아이템이 인벤토리에 들어가지 않으면 사라지지 않고 미수령함에 쌓입니다. 공간을 비운 뒤 `/financial claim`으로 받으세요.

## 주식

종목 가격은 일정 주기(기본 10분)마다 바뀌며, 기준 가격 쪽으로 조금씩 돌아오려는 성질이 있습니다. 바뀌기 1분 전과 바뀐 직후에 채팅으로 알려 줍니다.

- `/financial stock` 창에서 종목을 **좌클릭**하면 1주 사고, **우클릭**하면 1주 팝니다. **Shift**를 누른 채 클릭하면 100주를 한 번에 거래합니다. 가진 주식이 100주보다 적으면 전부 팔고, 100주를 살 돈이 없으면 살 수 있는 만큼 삽니다.
- 종목 설명에 지금 가격, 보유 주식 수, 산 금액 합계(총투자금액)와 현재 가치가 나옵니다.
- 상장 중지된 종목도 보유 기록은 남고 `/financial stock holdings`에서 볼 수 있습니다.

관리자 명령어는 [관리자 명령어](admin.md#financial) 페이지를 보세요. 다른 명령어는 [명령어 목록](commands.md)에 있습니다.
