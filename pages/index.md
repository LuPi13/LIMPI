# LIMPI 도움말

**LuPi13's Integrated Minecraft Plug-In**의 명령어 안내 페이지입니다.

접속할 때 나오는 **[도움말 보기]**를 누르면 이 페이지로 옵니다. 게임 안에서는 `/limpi help`로 모든 도움말을 모아 볼 수 있고, `/ability help`(`/ab help`), `/financial help`(`/fc help`), `/chest help`(`/ch help`), `/notice help`(`/nt help`)는 채팅에 명령어 사용법을 보여 줍니다. 첫 줄의 **[웹 도움말]**을 누르면 이 사이트의 명령어 페이지가 열립니다.

<div class="grid cards" markdown>

- **[명령어](commands.md)**

    모든 플레이어가 쓰는 능력·뽑기·퀘스트·계좌·수표·상점·장터·주식·상자·공지 명령어

- **[관리자 명령어](admin.md)**

    서버 관리자(OP)가 쓰는 능력 지정, 잔액 조정, 상점·주식 관리, 상자 조회, 공지 등록, 거래 복구 명령어와 설정 파일

</div>

## 명령어 줄여 쓰기

| 명령어 | 줄임말 |
| --- | --- |
| `/ability` | `/ab` |
| `/financial` | `/fi`, `/fc` |
| `/chest` | `/ch` |
| `/notice` | `/no`, `/nt` |

하위 명령어는 대소문자를 구분하지 않고, 탭 키로 자동 완성할 수 있습니다. 탭 완성과 게임 안 도움말에는 내가 쓸 수 있는 명령어만 나옵니다.

게임 안 도움말(`/<명령어> help`)에서 명령어 줄에 마우스를 올리면 자세한 설명이 보입니다. 누르면 입력할 것이 없는 명령은 바로 실행되고, 입력할 것이 있는 명령은 채팅 입력칸에 채워집니다. 관리자는 맨 아래 **[관리자 명령어 보기]**(`/<명령어> help admin`)로 관리자 명령어를 따로 봅니다.

!!! note "서버마다 다를 수 있는 값"
    이 페이지의 가격·확률·수수료 등은 플러그인 기본 설정 기준입니다. 서버 관리자가 설정을 바꿨다면 게임 안의 `/ab rates`(뽑기 확률), `/ab pity`(내 천장), `/ab shop`·`/ch shop`(가격)으로 실제 값을 확인하세요.
