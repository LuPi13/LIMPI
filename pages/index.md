# LIMPI 도움말

**LuPi13's Integrated Minecraft Plug-In**의 명령어 안내 페이지입니다.

게임 안에서 `/ability help`(`/ab help`), `/financial help`(`/fc help`), `/chest help`(`/ch help`)를 입력하면 나오는 도움말 책의 첫 장에서 이 페이지로 올 수 있습니다.

<div class="grid cards" markdown>

- **[명령어](commands.md)**

    모든 플레이어가 쓰는 능력·뽑기·퀘스트·계좌·수표·상점·장터·주식·상자 명령어

- **[관리자 명령어](admin.md)**

    서버 관리자(OP)가 쓰는 능력 지정, 잔액 조정, 상점·주식 관리, 상자 조회, 거래 복구 명령어와 설정 파일

</div>

## 명령어 줄여 쓰기

| 명령어 | 줄임말 |
| --- | --- |
| `/ability` | `/ab` |
| `/financial` | `/fi`, `/fc` |
| `/chest` | `/ch` |

하위 명령어는 대소문자를 구분하지 않고, 탭 키로 자동 완성할 수 있습니다. 탭 완성과 게임 안 도움말에는 내가 쓸 수 있는 명령어만 나옵니다.

!!! note "서버마다 다를 수 있는 값"
    이 페이지의 가격·확률·수수료 등은 플러그인 기본 설정 기준입니다. 서버 관리자가 설정을 바꿨다면 게임 안의 `/ab help`, `/ab pity`, `/ch help`로 실제 값을 확인하세요.
